# Julieto Hondrada — My Digital Portfolio

## Files
- `index.html` — portfolio content and navigation
- `style.css` — responsive styling and the visual theme

## How to use
1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in a web browser.
3. To publish it, upload both files to your hosting provider.

## Personalize before publishing
- Replace `your-email@example.com` in `index.html` with your real email address.
- Update the project descriptions and add links or screenshots for your actual work.
- Edit the About and Skills sections to reflect your current experience.

The design follows the supplied reference: deep navy, fresh teal, soft coral, warm off-white, Poppins headings, clean cards, and generous spacing.
